รายชื่อเพื่อน คนที่ผมติดตาม และครีเอเตอร์ที่ inspire โปรเจกตของผม, บน X, GitHub, YouTube หรือที่ไหนก็ตามที่พวกเขาโพสต์ ไม่ใช่ blogroll แบบแลกลิงก์

## เว็บนี้

ถ้าต้องการลิงก์กลับ:

```yml
- name: Umi4Life / Zekamashi
  url: https://umi4.life/
  desc: Custom Controllers, homelab, self-hosted service และการทดลอง infrastructure
  image: https://umi4.life/avatar/avatar.webp
```

## อยากให้ผมติดตาม?

ถ้าอยากให้เพิ่มในรายชื่อนี้หรืออยากให้ผมติดตามกลับ ฝากข้อความในคอมเมนต์ด้านล่าง (Waline ในหน้านี้) หรือติดต่อทางอื่นก็ได้ วางแบบนี้:

```yml
- name: YourHandle
  url: https://your-site-that-is-not-down.example/
  desc: "Engineering ที่พังแล้วสอนอะไรได้, Rhythm Game, หรือ debug เกินเวลานอน"
  image: https://yoursite.example/avatar-that-actually-loads.webp
```
